How to use this site
  1. Get started. Choose Start practice to open your form. At first, you’ll see only your own work.
  2. Add a place. Give the place a name or describe where it is. Share a safety concern, an idea for a change, or a community asset. A community asset is a place that helps people feel safe or connected. Tell us why the place matters. Try marking it on the map so others can find it, but a written location works too. To add a point, search for the place or pick a spot on the map, then check where the point lands.
  3. Save and see what others shared. Choose Save practice contribution and wait for “Practice contribution saved.” Then choose Review earlier input. Open a place someone else added and reply if you’d like. Use Check for new input to see what’s new.
  4. Wrap up. Want to come back later? Open Your return code and copy it. Keep it somewhere private. When you’re done, choose Finish on this device and confirm. Others can still see what you saved.

Accessibility and keyboard help
  • Use Tab and Shift + Tab to move between controls. Press Enter or Space to activate a button or open a collapsible section. Use arrow keys to move between radio-button answers.
  • The Skip to the current task link appears when focused. It moves you past the introduction to the current form or contribution.
  • A map point is recommended when contributing, but a written location is enough. Every contribution is available in the list. Named map buttons are an alternative to dragging or using map shortcuts.
  • Press Escape to close a dialog without confirming an action. Focus returns to the control that opened it.
  • You can enlarge text with your browser’s zoom controls. The page supports your system’s reduced-motion and high-contrast preferences.
About the demo, sources, and participation choices

This demonstration supports focused sessions and later review. The participant community, partner organization, real-world action, and final categories have not been validated with human participants.

Begin by contributing a place from your own perspective, then enter review to explore other contributions. Response totals are hidden until you choose to view them. A different experience is not a judgment that another account is false.

One saved answer for each practice identity, contribution version, and responding session; you can update or remove it.

Authors can edit or withdraw their own demo contributions. Editing replaces the wording and creates a new version. Older answers are excluded from the current summary and export. Withdrawal clears the description and removes its answers and opening records.

Address and intersection searches use the City of Philadelphia’s public geocoder; a small local index supplies landmark examples. Queries are sent only when Search is pressed. The contribution text and practice code are not sent to the City. Returned points are approximate and should be checked. Any place can be described without a point. The map supports point placement, keyboard controls, and coordinate entry.

Address and intersection lookup: City of Philadelphia geocoder.

Street basemap: © OpenStreetMap contributors. Viewing the map requests tiles for the visible area from OpenStreetMap; contribution text and practice codes are not sent. Map features are geographic context, not safety ratings. Points are restricted to Philadelphia city limits.

Group review uses PEMA 2021–2023 aerial imagery via PASDA. Only visible map areas are requested; contribution text and practice codes are not sent. Street View opens Google Maps only when its link is selected.

City boundary: City of Philadelphia City Limits. The same published outline is used for point selection and saves.

All starting accounts are fictional and start with zero responses. There has been no accessibility certification or human testing. Server-side storage is for practice records only; a retention, moderation, and participant-feedback agreement is needed before real collection.

Available in review. Exports include all available sessions, regardless of view filters. GeoJSON includes described places with null geometry. Only current-version answers are exported in JSON/CSV. Codes, identity hashes, response comments, and historical answers are omitted.
